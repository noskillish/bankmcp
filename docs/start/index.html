Get started

Two ways to run BankMCP™. On a server you can use it from claude.ai and on your phone; on your own machine it needs no server at all.

On a server · about ten minutes

Deploy, then set up in the browser.

01

Deploy

One click in your own Railway account creates the server, its storage and its address. Railway bills the server; nothing is paid to us.

02

Paste the address

When the card in Railway turns green it shows an address ending in .up.railway.app. Paste it here. This page waits for the server and opens its setup page.

Open setup →

03

Finish setup

The setup page asks for an Enable Banking application, free for your own accounts, and a password, and shows the values their form needs with Copy buttons. Then add the connector address to your assistant and say connect my bank.

Other hosts: Fly, Render and Docker.

On your own machine · about five minutes

No server.

With Node 24 or later, add npx -y bankmcp to your MCP client, or install the Claude Desktop bundle from the latest release. The server runs on your machine and shows its setup page at https://localhost:8080. It works while your machine is on; for claude.ai and your phone use a server.
